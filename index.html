Welcome to the official Cattle Engine website. Here you'll find information, updates and resources related to the development of Cattle Engine.

Cattle Engine is a custom game engine currently in development, featuring full 2D support and basic 3D HDR rendering.
It uses Angelscript as the primary way for developers to code games.

The project is open source and can be found on GitHub.

About Cattle Engine

Cattle Engine is being developed as a custom game engine with the goal of providing a straightforward development experience,
following the old school ways of engines like Source Engine.

Current Features

  • Full 2D support
  • Basic 3D rendering
  • HDR rendering
